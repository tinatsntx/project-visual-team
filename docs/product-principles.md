# Product principles

Condensed from PROJECT_PLAN.md §3 — read the plan for the full text.

1. **One bot by default.** Small requests get one lead bot, not theater.
2. **Truth before animation.** Every state is backed by an observed event, a
   reported boundary, a derived inference with limits, or a user action.
3. **Native capabilities first.** ChatGPT/Codex do the work; we make it
   understandable.
4. **Consumer language, inspectable details.** Plain words up front; an
   evidence panel carries provenance.
5. **Permissions stay native.** We explain, never replace.
6. **Minimal data collection.** Metadata only.
7. **Accessible without animation.** Text for every state, reduced motion,
   keyboard navigation, screen readers, WCAG AA.
