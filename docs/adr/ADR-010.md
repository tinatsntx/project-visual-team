# ADR-010: Public name selected only after clearance

**Status:** Accepted

## Decision

"Project Visual Team" is a working codename. The public name is chosen only
after name, domain, repository, and trademark screening.

## Rationale

Renaming after publication is costly and conflicts are a listed risk.

## Consequences

- Repo, plugin `name`, and docs use the codename or neutral wording.
- No public branding, submission, or domain purchase before clearance.
