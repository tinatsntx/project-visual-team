# ADR-002: No Agents API in MVP

**Status:** Accepted

## Decision

The MVP does not use the OpenAI Agents API. The codebase contains an
`ExecutionAdapter` boundary with only a native-host implementation.

## Rationale

The Agents API changes billing, account setup, and product positioning.
Adopting it is a separate product decision, never a silent refactor.

## Consequences

- Any future proposal to add the Agents API requires an explicit
  architecture review and a new ADR superseding this one.
- If native execution cannot provide durable work or required events, the
  feasibility report must say so instead of silently escalating scope.
