# ADR-003: No Codex App Server or standalone client in MVP

**Status:** Accepted

## Decision

No Codex App Server integration, desktop client, or mobile app is built in
the MVP.

## Rationale

A separate client is a different product surface with its own distribution,
auth, and maintenance costs. If the feasibility gate shows one is required,
that returns to a product decision before any build work.

## Consequences

- Surfaces are limited to ChatGPT (web/desktop/mobile) and Codex via plugin.
