# ADR-009: Apache-2.0 code license

**Status:** Accepted

## Decision

Code is licensed Apache-2.0. The eventual project name and logo are kept
outside the license via a simple trademark policy.

## Rationale

Permissive, patent-granting, and standard for open-source developer tools.

## Consequences

- `LICENSE` carries Apache-2.0; `TRADEMARK.md` will be added at naming.
