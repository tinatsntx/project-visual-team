# ADR-006: Metadata-only persistence

**Status:** Accepted

## Decision

The state service stores only what the display needs: opaque task id,
optional title, role labels, state events, timestamps, provenance, and
host-supplied artifact references. Never prompts, transcripts, source code,
command text/output, file contents, generated artifacts, or credentials.
In-memory storage for the alpha; PostgreSQL only if/when public multiuser
persistence is required.

## Rationale

Minimal data means minimal breach surface and an honest privacy story.

## Consequences

- `record_codex_event` payload schemas whitelist correlation fields only.
- Logs redact capability tokens and user-supplied text.
