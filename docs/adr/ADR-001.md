# ADR-001: Plugin-first architecture

**Status:** Accepted

## Decision

Project Visual Team ships as an open-source ChatGPT/Codex Plugin — a portable
Agent Plugins package (`plugin.json`) bundling a skill, an MCP state server,
and MCP Apps UI. No standalone client, no independent agent runtime.

## Rationale

ChatGPT and Codex already own reasoning, tools, subagents, and permissions.
The product's value is legibility of that existing work, not a new platform.

## Consequences

- All distribution, install, and trust flows go through plugin surfaces.
- Anything the host cannot surface (custom chrome, persistent chrome-side UI)
  is out of scope.
