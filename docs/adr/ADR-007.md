# ADR-007: Native approvals are never replaced

**Status:** Accepted

## Decision

The plugin may show that permission is needed but must never approve, deny,
rewrite, auto-answer, or obscure native ChatGPT/Codex permission controls.
`record_codex_event` is append-only and returns no decisions.

## Rationale

Approval automation is a safety boundary, not a UX problem.

## Consequences

- The hook script always exits 0 and emits no decision payload.
- A user request to auto-approve is refused by the skill (negative eval).
