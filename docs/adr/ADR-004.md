# ADR-004: Truthful event provenance — no agent theater

**Status:** Accepted

## Decision

Every displayed state carries provenance: `observed` (real hook/tool event),
`reported` (explicit model-reported boundary), or `derived` (server inference).
Derived evidence may never claim completion, approval, review, or success.
Stale activity degrades to "No recent activity", never "stuck" or "failed".

## Rationale

The product fails if animation implies work that did not happen. Provenance
is enforced in the state machine, not just in copy.

## Consequences

- Completion requires an explicit completion event.
- Approval requires a real permission event or user-decision request.
- Blind spots (hosted tools, missing hooks) are disclosed, not papered over.
