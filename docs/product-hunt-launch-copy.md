## Maker comment

Hi Product Hunt! I built Visual Team because it is easy to lose track of
whether an AI coding task is working, waiting for me, or reporting a result.

Visual Team puts those signals in a small board inside ChatGPT: pending
approvals, recent recorded activity, the current reported phase, and the
reported result. It distinguishes native hook evidence from model-reported
status. Approvals still happen in Codex; the board cannot approve an action.

You can explore a clearly labelled sample immediately, without signing in.
The source and self-host instructions are available now. This is a working
alpha: the tested live path is ChatGPT web with Windows Codex CLI
0.154.0-alpha.6.2, and setup requires your own server and developer app.
Tasks are ephemeral, with no account system or persistent history yet.

Built with GPT-6 Astra in Codex for development coordination and some
implementation, alongside other development tools. SWE-2 in Devin also
contributed implementation. This describes how the product was built;
Visual Team does not require Astra as an embedded runtime model.

I would love feedback on one thing: can you tell what needs your attention
without reading through a long coding conversation? Try the sample and tell
me which status or evidence label is still unclear.
